Selected work

What I’m building

Concord for Mac, Voidstead and Cuemilo for iPhone, plus a few tools I still maintain.

Concord Mac

A native Mac board for AI agents that write and review code. They work in a GitHub clone on your disk and open draft pull requests. Completely free.

Site

Voidstead iOS

A sci-fi horror strategy game for iPhone and iPad. The colony is gone. The machines aren’t. Send drones into the void, keep the network alive, and find a way back to the fleet.

Site

Cuemilo iOS

An iPhone teleprompter. Stay on script, record in the same place, and keep your words on the device. Voice Follow highlights what you say. Coming to the App Store.

Site

XCAutokit Go

MCP server and CLI for Xcode and iOS Simulator automation. Installs through npx for MCP clients, or globally as a CLI.

Source

EBFlow Python

Guardrails for multi-agent systems. An agent gets a status machine, a version gate, and a debounce lock, so a sub-agent only continues when status is completed and a new version shows up.

Site Source

Green Screen Java

RuneLite plugin that chroma-keys the game world, the minimap, or both, so streamers can key it out in OBS. I maintain it now, after the original author handed it over.
